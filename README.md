Week 4 – Web Application Security Assessment

Project Overview

This project documents my Week 4 practical learning as part of the Networkwalks Cybersecurity Internship. The work focuses on initial web reconnaissance and basic security observations for a web application.

Project Type: Black-Box Web Application Assessment
Week: 4
Tools: Kali Linux, cURL, Firefox

Objectives

- Understand basic web reconnaissance.
- Inspect the "robots.txt" file.
- Examine HTTP response headers.
- Observe a web application's login interface.
- Learn about session cookie security and access-control considerations.

Tasks Performed

1. robots.txt Analysis

Retrieved and reviewed the "robots.txt" file using cURL to identify paths listed in its directives.

2. HTTP Response Header Analysis

Used cURL to inspect the HTTP response and review available response headers.

3. Patient Portal Observation

Observed the patient portal login interface and studied the importance of secure session management.

4. Lab Reports Page Observation

Reviewed the lab reports page and considered the role of authentication and authorization in protecting sensitive information.

Tools Used

- Kali Linux
- cURL
- Firefox

Key Learnings

- Basic website reconnaissance
- HTTP status codes and response headers
- Understanding "robots.txt"
- Session cookie security
- Authentication and authorization concepts

Conclusion

This practical exercise helped me develop a better understanding of web application reconnaissance and fundamental security assessment techniques.
